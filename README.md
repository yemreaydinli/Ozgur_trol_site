# Date Troll 💗

Gönderilen Reels ekran görüntülerindeki pastel/pembe, minimal kart tasarımından esinlenen responsive date davet sitesi.

Akış:
1. "Benimle date'e çıkar mısın?"
2. Evet -> kabul ekranı
3. Tarih seç
4. Date aktivitesi seç:
   - Dinner Date
   - Cute Cafe
   - Arcade or Fair
   - Movie Night
   - Picnic
   - Sunset Walk
5. Tebrik / date kesinleşti ekranı

Hayır butonu:
- Masaüstünde imleç yaklaşınca kaçar.
- Mobilde dokunma gerçekleşmeden başka yere taşınır.
- Ekstra "neden hayır dedin?" mesajı göstermez.
